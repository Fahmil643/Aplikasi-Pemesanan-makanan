Aplikasi ini adalah sistem pemesanan makanan Mie Gacoan berbasis web dengan dua portal utama:

Fitur Yang dimiliki Pelanggan

- Memilih menu berdasarkan kategori: mie, dimsum, dan minuman.
- Mencari menu menggunakan fitur pencarian.
- Memilih tipe pesanan Dine In atau Take Away.
- Mengisi nomor meja dan nama pemesan.
- Mengatur level kepedasan mie dari level 0 sampai level 8.
- Menambahkan catatan khusus dan jumlah pesanan.
- Mengelola keranjang belanja.
- Menghitung subtotal, PPN restoran 10%, dan total pembayaran.
- Mendukung pembayaran QRIS, e-wallet, atau tunai.
- Melacak status pesanan secara langsung.
- Portal Dapur dan Kasir

Fitur Yang dimiliki Penjual
- Menampilkan pesanan yang masuk secara real-time.
- Mengubah status pesanan:
- Menunggu Konfirmasi
- Sedang Dimasak
- Siap Disajikan
- Selesai
- Dibatalkan
- Menampilkan total omzet, jumlah pesanan, antrean dapur, dan menu terlaris.
- Memfilter pesanan berdasarkan status.
- Mengatur ketersediaan stok menu.
- Menampilkan dan mencetak struk pembayaran.
